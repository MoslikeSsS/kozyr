# ♠ КОЗЫРЬ — Карточные игры онлайн

Покер (Техасский холдем) и Дурак (подкидной/переводной) в одном приложении с поддержкой мультиплеера через браузер.

![КОЗЫРЬ](https://img.shields.io/badge/Игры-Покер%20%7C%20Дурак-gold)
![GitHub Pages](https://img.shields.io/badge/Deploy-GitHub%20Pages-blue)

## 🎮 Возможности

### Покер (Техасский холдем)
- Полная реализация правил: блайнды, торги, олл-ин, сайд-поты
- Живые подсказки комбинаций (справочник справа)
- Оценка силы руки на префлопе (формула Чена)
- Таймер хода 25 секунд с авто-чеком/фолдом
- Анимации карт, звуки, баннеры победителей

### Дурак
- 36 карт, козырь под колодой
- Подкидной и переводной режимы
- **Подсказки с подсветкой:**
  - 🔴 Красное свечение — карты для битья
  - 🟡 Жёлтое свечение — карты для перевода хода
  - 🟢 Зелёное свечение — карты для подкидывания
- Автоматическое определение проигравшего

### Мультиплеер
- Комнаты по 3-значному коду
- До 6 игроков за столом
- Добавление ботов для тренировки
- Чат во время игры
- Админ-панель хоста (кик, блайнды, рестарт)

## 🚀 Быстрый старт

### Онлайн (GitHub Pages)

Игра доступна по адресу: **https://<ваш-username>.github.io/kozyr/**

1. Откройте ссылку в браузере
2. Введите имя
3. Нажмите **"Создать комнату"** — получите 3-значный код
4. Отправьте код друзьям — они вводят его и нажимают **"Войти в комнату"**
5. Нажмите **"Начать игру"**

**Важно:** Для онлайн-игры нужен интернет (используется публичный PeerJS-сервер для знакомства браузеров, дальше трафик прямой).

### Локально (без интернета)

```bash
# Установка
npm install

# Сборка
npm run build

# Запуск локального сервера
node server.mjs
```

Сервер напечатает ссылки:
```
  ♠  КОЗЫРЬ — локальный сервер готов
  ─────────────────────────────────────────
  Для себя:     http://localhost:9000
  Для игроков:  http://192.168.1.15:9000
```

Раздайте ссылку "Для игроков" — всё работает в локальной сети без интернета.

### Режим разработки

```bash
# Терминал 1: игра
npm run dev

# Терминал 2: сигнализация
node server.mjs
```

Игра на `http://localhost:3000`, сигнализация на `http://localhost:9000`.

### Быстрая игра с ботами

На главной странице нажмите **"Играть"** — запустится одиночная партия против ботов (работает полностью офлайн, без сервера).

## 🛠 Технологии

- **React 18** + TypeScript
- **Vite** — сборка
- **Tailwind CSS 4** — стили
- **PeerJS** — WebRTC для P2P-соединения
- **WebAudio** — звуки
- **Framer Motion** — анимации

## 🎯 Как играть

### Покер

1. **Создайте комнату** и получите код
2. **Пригласите друзей** — они входят по коду
3. **Начните игру** — каждому раздадут 2 карты
4. **Торги:** фолд / чек / колл / рейз
5. **Подсказки** справа показывают вашу комбинацию
6. **Победитель** забирает банк

### Дурак

1. **Выберите режим:** подкидной или переводной
2. **Создайте комнату** и пригласите игроков
3. **Козырь** лежит под колодой
4. **Атакующий** кидает карту (зелёная подсветка)
5. **Защищающийся** бьёт (красная подсветка) или переводит (жёлтая подсветка)
6. **Бито** — все карты в отбой
7. **Проигравший** — тот, кто остался с картами

## 🔧 Настройка GitHub Pages

### Автоматический деплой

1. Создайте репозиторий на GitHub
2. Запушьте код
3. Перейдите в **Settings → Pages**
4. В **Source** выберите **GitHub Actions**
5. При каждом пуше в `main` сайт будет автоматически деплоиться

Сайт будет доступен по адресу: `https://<username>.github.io/<repo-name>/`

### Ручной деплой

```bash
# Сборка
npm run build

# Загрузите папку dist/ в ветку gh-pages
git subtree push --prefix dist origin gh-pages
```

## 🌐 Сетевая архитектура

### Онлайн (GitHub Pages)
- **Сигнализация:** публичный PeerJS-сервер (`0.peerjs.com`)
- **Игровой трафик:** прямой WebRTC между браузерами
- **Интернет нужен** только для знакомства браузеров

### Локально (node server.mjs)
- **Сигнализация:** локальный сервер на порту 9000
- **Игровой трафик:** прямой WebRTC между браузерами
- **Интернет не нужен** — работает в изолированной сети

## 🐛 Известные ограничения

- PeerJS-сервер может быть временно недоступен (редко) — в этом случае используйте локальный сервер
- WebRTC требует современный браузер (Chrome, Firefox, Edge, Safari 11+)
- В Safari на iOS могут быть проблемы с автоплеем звуков (нужно первое взаимодействие)
